What am I looking at?

Mostly Bash configuration focused on usability. Pick your favorite colors and do a quick install to take advantage of the features below, or read about the motivation behind the project. Share your theme with others with the generated URL.

Features:

  • ( user @ {{ previewHostname }}:pts/5 ) - Username (highlighted if root) and hostname.
  • ( {{ segment.glyph }} ) - Unique host avatar based on hostname. Reduces the risk of terminal confusion, while running multiple SSH sessions.
  • ( 1 ↻ ) - Shows number of background processes if more than zero.
  • ────── - Line separating commands output.
  • ( 127 ↵ ) - Shows exit code if other than zero.
  • ( Wed May 14 ) ── ( 00:40:12 ) - Date and time. Time changes color if exit code other than zero.
  • ( 42s ) - Duration of the previous command in seconds, in the primary color whatever that command ended with.
  • ( ~/repo ) - Current directory.
  • ( $ on master = ) - Git status (if current directory inside git repository).
  • <cmd_prefix> + ⇅ - Rapid search history with up/down keyboard arrows
  • ┈─ ( ~/repo ) ─ ( $ ) -> - Alt+t keeps only the line you type on, for a terminal with more to show than the frame can spare; Alt+t again brings the frame back. It takes the key from readline's transpose-words.

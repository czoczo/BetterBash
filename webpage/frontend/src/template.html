Other features:

  • ( user @ {{ previewHostname }}:pts/5 ) - Username (highlighted if root) and hostname.
  • ( 1 ↻ ) - Shows number of background processes if more than zero.
  • ────── - A line the width of a terminal window that separates command results.
  • ( 127 ↵ ) - Shows exit code if other than zero.
  • ( Wed May 14 ) ── ( 00:40:12 ) - Date, and a clock in the error color after a failed command.
  • ( 42s ) - Duration of the previous command.
  • ( ~/repo ) - Current directory.
  • ( $ on master = ) - Git status, inside a repository.
